### Jiho Yun

Student in Singapore. I run small, reproducible experiments in AI safety and quantitative finance, and publish the code and data with the result.

**Selected work**

- [**Cutting the Wire**](https://github.com/groothaha/vector-channel-countermeasures) — Two frozen LLMs can learn to talk in vectors a text monitor can't read (94–96% recall vs 29–37% for a text message of the same budget). Snapping each vector to its nearest token embedding removes all 49 channels we trained. *Apart Research, AI Collusion Research Sprint, Oct 2026.*
- [**Overnight risk premium**](https://github.com/groothaha/overnight-risk-premium) — Nasdaq-100 futures held 16:00 → 09:00 ET earn +7.26 bp a night (t = 5.23) when the index is above its 200-day average; the other nights are flat (−0.87 bp). Data included, two scripts reproduce every number.
- [**Forward ledger proofs**](https://github.com/groothaha/forward-ledger-proofs) — A private paper-trading record, hash-chained three times a trading day and timestamped by two RFC 3161 authorities and OpenTimestamps, so the results can't be backfilled.
